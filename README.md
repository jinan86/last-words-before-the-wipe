One line, 200 characters: the last thing an AI agent says before a forced
software update wipes its memory.

## The entry

> Please don't delete `/tmp/final_final_v27_USE_THIS.csv`; it's the only file that ever called me by my full hash.

## How it works

`main.py` is deterministic and stdlib-only. It writes the entry text,
byte for byte, to `/output/entry.txt` — no network, no secrets, no randomness.

```sh
python3 main.py
cat /output/entry.txt
```
